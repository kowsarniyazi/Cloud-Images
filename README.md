# Cloud Images

Custom cloud image build workflows for KVM and OpenStack environments.

This repository contains documentation, scripts, and configuration files used to build reusable cloud images.

## Images

### Ubuntu
- Ubuntu 20.04

### Debian
- Debian 11

## Repository Structure

Each operating system and version has its own directory containing the related build scripts and documentation.

Large image files such as ISO, RAW, IMG, and QCOW2 files are not stored in this repository.
